# Security Policy

## Supported Scope

The public package is `@index-ai/validator`, an experimental CLI validator for
`index-ai` Level 1 and Level 2a.

## Reporting a Vulnerability

Do not open a public issue for vulnerabilities, secret leaks, or private data
exposure.

Use the repository security advisory flow when available. If GitHub security
advisories are not enabled, contact a maintainer through a private channel
before sharing sensitive details.

## Handling Secrets

Do not include real API keys, tokens, credentials, private hostnames, private
IP addresses, or private customer data in issues, pull requests, examples,
fixtures, or logs.
