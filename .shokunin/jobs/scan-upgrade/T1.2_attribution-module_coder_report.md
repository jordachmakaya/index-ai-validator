## Implementation approach

- `AttributionSrc = 'cli-json' | 'cli-report' | 'cli-terminal'` — the full contractual union.
- `rewriteAttributionSrc(auditUrl: string, src: Exclude<AttributionSrc, 'cli-json'>): string` — the parameter's rewrite-target type is derived from the union via `Exclude`, not hand-duplicated, so `'cli-json'` is rejected at compile time (both `@ts-expect-error` lines in the test stay valid, confirmed by a clean `tsc --noEmit`).
- Parses `auditUrl` with native `new URL()`; on failure throws `InvalidAuditUrlError` (never a fallback/invented URL). On success, mutates only the `src` param via `URLSearchParams.set('src', src)` — `.set()` updates a key already present in place without reordering or touching any other param (verified against the `utm_campaign` + key-order test), so `scanId` and any other query param survive untouched, per CONTRACT_SCANNER.md §6 rule 1 ("ne jamais construire l'URL à la main, toujours dériver de `meta.links.audit`").
- Style aligned with `utils/url.ts`: error class with `override name`, `cause` chaining via `ErrorOptions`, try/catch isolated in a small `parseAbsoluteAuditUrl` helper. No import from `url.ts` (different concern, per job note).
- No new dependency — native `URL`/`URLSearchParams` only.
- `@filemeta` block added at the top of the new file per `shokunin-filemeta`.
