## API contract assumed by the tests (for the Coder job)

Since `utils/attribution.ts` does not exist, this Tester job had to fix the
exact surface the tests import, per `IMPLEMENTATION_PLAN.md` §T1.2 and
`CONTRACT_SCANNER.md` §6/§9:

- `rewriteAttributionSrc(auditUrl: string, src: 'cli-report' | 'cli-terminal'): string`
  — parses `meta.links.audit` as already received from the scanner, replaces
  only the `src` query param, returns the URL as a string with everything
  else (protocol, host, path, `scanId`, any other param, param order)
  untouched.
- `type AttributionSrc = 'cli-json' | 'cli-report' | 'cli-terminal'` —
  exported, wider than the function's `src` parameter (`'cli-json'` is a
  valid `AttributionSrc` value — it's what the scanner sends — but not a
  valid rewrite target).
- `InvalidAuditUrlError extends Error` (named after the style of
  `utils/url.ts`'s `InvalidTargetUrlError`, i.e. `override name`, thrown for
  a malformed/non-absolute `auditUrl`) — thrown explicitly, never a silent
  fallback that invents a URL.

## 6 test cases written

1. `rewrites src to cli-report for the HTML report context` — real fixture
   from `CONTRACT_SCANNER.md §9`, asserts `src=cli-report` and `scanId`
   unchanged.
2. `rewrites src to cli-terminal for the terminal message context` — same
   fixture, asserts `src=cli-terminal` and `scanId` unchanged.
3. `preserves protocol, host, path, scanId, and every other query param
   untouched` — fixture extended with an extra `utm_campaign` param;
   asserts protocol/host/pathname unchanged, `scanId` and `utm_campaign`
   preserved, and the exact param key order (`src`, `scanId`,
   `utm_campaign`) is stable — only `src`'s value changes.
4. `throws an explicit InvalidAuditUrlError on a malformed audit URL instead
   of inventing one` — asserts the typed error class, not a generic throw.
5. `rejects cli-json at the type level` — `// @ts-expect-error` on
   `rewriteAttributionSrc(auditUrlFixture, 'cli-json')`, documenting that
   `'cli-json'` is the value already received from the scanner and is never
   a valid rewrite target; if the parameter type regresses to accept it,
   `pnpm check` (typecheck) will surface the missing compile error.
6. `exported AttributionSrc union covers cli-json, cli-report, and
   cli-terminal` — asserts a `AttributionSrc[]` literal array of all three
   values, assigns `'cli-json'` to a `const: AttributionSrc` (compiles
   fine, proving the union is wide enough), then a second
   `// @ts-expect-error` on passing that same `AttributionSrc`-typed value
   into `rewriteAttributionSrc`, proving the function's parameter is
   narrower than the exported union.

No network call anywhere in this file — the module only parses/rewrites an
in-memory URL string, per JOB.md's explicit note.
